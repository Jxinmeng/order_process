## 可用的最小执行单元

你可以使用以下原子函数进行组合。每个函数都已经在Python环境中可用，无需import。

### 日期处理

- `parse_date(date_str)` : 将字符串解析为datetime对象
  示例: dt = parse_date("2026.8.19")

- `format_date(dt, fmt="%Y.%m.%d")` : 将datetime格式化为字符串
  示例: date_str = format_date(dt)

- `add_days(dt, days)` : 日期加天数
  示例: new_dt = add_days(dt, 30)

### 字段操作

- `get_field(row, field, default="")` : 从字典中获取字段值
  示例: value = get_field(row, "日期")

- `set_field(row, field, value)` : 在字典中设置字段值，返回修改后的字典
  示例: row = set_field(row, "交货日期", "2026.9.19")

### 条件判断

- `if_contains(value, keyword)` : 判断字符串是否包含关键词
  示例: if if_contains(model, "客户A款"): ...

- `if_equals(value, target)` : 判断字符串是否相等
  示例: if if_equals(req, "加急"): ...

### 值映射

- `map_value(value, mapping)` : 根据映射表转换值
  示例: mapped = map_value(model, {"客户A款": "A-2026-011"})

### 文本、编号和工作日

- `split_before(value, separator)`：取分隔符前的文本
- `remove_prefix(value, count=1)`：移除前 count 个字符
- `pad_left(value, length, char="0")`：左侧补齐
- `concat(values, separator="")`：拼接非空值
- `parse_excel_date(value)`：解析 Excel 日期序列或文本日期
- `move_to_previous_workday(dt)`：周末前移到最近工作日
- `previous_workday(dt)`：返回严格早于 dt 的最近一个工作日
- `add_workdays(dt, days)`：按工作日加减天数，跳过周末

### 使用规范

1. 输入数据在 `row` 变量中（dict类型）
2. 处理后的结果要写回 `row` 变量
3. 可以组合多个原子函数
4. 注意处理None值和异常情况
